## Taxonomy (§11.1) — exactly the proposal's 8 classes

`transient`, `waiting`, `semantic_failure`, `authority`, `capability`,
`environment`, `ambiguous`, `cancelled`(=operator terminal). Plus the
fail-closed bucket `unknown` (NOT one of the 8; always `blocked` +
`need_attention` + recorded `classification_uncertainty`) and non-failure
progress classifications `none_dispatchable` / `none_awaiting_approval` /
`none_completion` / `none`.

## Observation inputs (authoritative channels only)

- `delegation.state / backend_state / outcome / validation_verdict`
  (enum-validated against `operator_delegations.STATES` / contract verdicts)
- `runner.observed_runs` latest status/outcome/error (`operator_runners`)
- `worker_exit.kind` mirroring host `_classify_worker_exit` vocabulary
  (`clean_exit` / `rate_limited` / `nonzero_exit` / `signaled` / `unknown`)
- `last_failure_error` token-matched against fixed vocabularies refined from
  host `_RESPAWN_BLOCKER_RE` — the refinement: throughput (rate_limit/429/5xx)
  → `transient` (retry), account/credential/policy (quota/auth/403/billing)
  → `authority` (park, never auto-retry)
- `capability` live-negotiation result (ok/not-ok + bounded reasons)
- `plan.node_state / parent_done / all_children_terminal / replan_attempts_used`
- `mission.status / final_approval_required`; `breaker` (failures/limit/gave_up)

## Decision ladder (deterministic, fail-closed first)

1. invalid enum anywhere → `unknown` (fail-closed)
2. operator terminal intent (cancelled / mission paused|blocked) → `cancelled`
3. missing observation (in-flight without run channel; nonzero exit without
   flavor; unflavored delegation/node/runner failure) → `unknown`
4. `reconciling` / `ambiguous` backend / `submission_may_have_succeeded` →
   `ambiguous` (observe only, never redispatch)
5. authority tokens → `authority` (park + escalate)
6. capability not-ok / no-capable-target tokens → `capability`
7. environment tokens (workspace/store/manifest/lease) → `environment`
8. semantic evidence (`NOT_SATISFIED` / `INVALID_CONTRACT` verdict, defect
   tokens, `clean_exit` protocol violation) → `semantic_failure` (+ D8-bound
   replan **proposal** while attempts < 1, never executed)
9. transient evidence (rate_limited/signaled exit kinds, throughput tokens) →
   `transient`; §8.1 breaker-open overrides to `breaker_exhausted` (no retry)
10. evidence gate: terminal success without verdict / `INCONCLUSIVE` →
    `unknown` on the `fail_closed_evidence` row (§11.2)
11. waiting rows → `waiting`
12. progress rows: dispatch-ready child / approval gate / completion request
13. steady state → `none`

`reclaim_dead_worker` (§11.2 row 2): node `running` + worker-exit `unknown`
→ smallest action = host `reclaim_task` + bounded retry (classification
`transient`, row override).

## Recovery matrix (§11.2) — deterministic lookup

15 rows, each `{observed, smallest_action, proposed_tool, verify, auto_retry}`.
Only `transient` carries `auto_retry=True` (and only while the breaker is
closed). Every action is a *request*: `would_execute` is a hard `False`
constant; no dispatch/reclaim/redispatch/approval code path exists in the
module. Dispatch proposals name the existing authority surfaces
(`hermes_swarm_stage_dispatch` / `hermes_contract_dispatch`).

## Safety properties (test-proven)

- **Fail-closed on missing observation** — 7 distinct `unknown` paths asserted
  with `classification_uncertainty` codes + `need_attention`.
- **Zero side effects** — dry-run records nothing; recording (workspace +
  direct + confirm) writes ONLY a `controller_plan` row; live smoke proves no
  `delegations` store is even created and `missions` count unchanged.
- **INV-9** — raw error text never persisted; only matched token ids
  (`class:token`), bounded enums, counts, sha256 digests; secret-shaped input
  redacted (asserted against the persisted `decision_json` blob).
- **Determinism** — canonical-JSON `decision_sha256`; same input → identical
  digest; key-order independent; different input → different digest.
- **D8 replan bound** — proposal only, `max_attempts=1`, `executed=False`,
  only for `semantic_failure`.
