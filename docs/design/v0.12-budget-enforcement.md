## 2. Enforcement contract (what to build)

### 2.1 Executor

Add to `operator_mission_budget.py`:

```python
def enforce_budget_breaker(mission_id, *, hermes_root=None, confirm=False) -> str
```
- Evaluates the mission's envelope + policy; if no crossing or `hard_block_enabled`/`pause_on_cross` are false → returns a no-op result (`enforced: false`, reason `not_crossing|disabled`).
- Full gate preconditions (ALL required; evaluated fresh, in this order — first failure returns its stable reason code, NO writes, NO partial action):
  1. `confirm=True` (per-call confirmation; dry-run-first convention).
  2. `HERMES_GPT_BUDGET_HARD_BLOCK=1` (global machine gate; default off — process-wide capability switch).
  3. Operator enabled + `apply_mode == "direct"` (live operator policy).
  4. Per-mission policy: `hard_block_enabled` and `pause_on_cross` true.
- On pass, performs the D3 action set **atomically from the caller's perspective**:
  1. **Anti-TOCTOU (INV-11):** re-snapshot the operator policy immediately before acting; if enabled/apply_mode changed since gate evaluation, abort with `refused: policy_changed` (no writes).
  2. **Pause:** call the existing transition `hermes_mission_transition(mission_id, "paused", reason="budget_breaker")` (parameter actually named per current runtime surface — verify at implementation; the reason string `budget_breaker` MUST appear in the transition audit). If the mission is not in a pausable state (`MISSION_TRANSITIONS`), do not dispatch further work and mark `need_attention: true` with reason `not_pausable` — fail closed.
  3. **Signal:** emit ONE fleet-attention INTERRUPT envelope through the existing spool (`operator_controller.spool_attention_envelope`), same `fleet-attention-envelope/v1` schema family, with `row_key="budget_breaker"`, `classification="budget_crossing"`, `proposed_action="pause_mission"`, bounded reasons (ids/enums only). Delivery remains the broker lane's job (never self-send). Spool failure raises (loud).
  4. **Record:** append a `budget_events` row `event_type="break"` carrying bounded fields only: `mission_id`, `spend_after`, envelope/quota numbers, `signal`, and `reason_sha256` style refs — never raw text (INV-9).
- Return envelope: `{success, mission_id, enforced: true|false, reason, need_attention, would_pause (from _would_block), breaker_signal, spend_after, transition: {applied, from, to} | null, spooled: bool}` — all bounded.
- Idempotency: calling again for an already-paused, already-broken mission returns `enforced: false, reason: already_enforced` and appends NO second `break` row (check the latest `budget_events` `break` row + mission state).

### 2.2 Existing-surface integration

- `hermes_budget_check(mission_id, hermes_root=None, enforce=False, confirm=False)`:
  - `enforce=False` (default): byte-identical to current behavior.
  - `enforce=True`: runs the gate evaluation and (only if all gates pass) calls `enforce_budget_breaker`. Result envelope gains `enforcement: {...}` sub-object mirroring `_would_block` plus `enforced` outcome. With any gate missing → `enforcement.enforced == false` + stable reason; no writes. (Dry-run-first: `enforce=True` without `confirm=True` is a preview.)
- `operator_controller.py` call-site (the ONLY controller change Pack A makes — union seam with Pack B):
  - In the reconcile pass, after classification and only when the pass's evaluated `would_pause` is true for the mission in scope, call the enforcement path with `confirm=<pass confirm>`; record the enforcement outcome in the pass envelope under `budget_enforcement` and in telemetry. When enforcement is disabled, the envelope field must be `null` (or absent) exactly as today so L0/L1 outputs stay byte-identical.

## 3. Authority rules (INV-1 no self-escalation)

- The pause is Owner-class per D3; the controller may EXECUTE it only under the full gate set above.
- The controller NEVER resumes a mission, NEVER raises a quota, NEVER lowers a quota to escape an overrun. Resume/quota changes remain `O`-ACK human paths (distinct principal from the pauser). No new tools for any of this.
- `pause_on_cross=False` means: report only, never pause (existing dry-run reporting still applies).

## 4. Storage + invariants

- No new tables. `budget_events.event_type="break"` is the only new value. INV-9: bounded numbers/ids/enums/refs only.
- INV-2: an over-envelope mission is never auto-completed by any path touched here; enforcement only pauses.
- INV-8: within-envelope spend stays ungated; the crossing edge is the only trigger.
- INV-11: the anti-TOCTOU re-snapshot is mandatory and must be covered by a test that flips the policy between gate evaluation and action (monkeypatched policy loader) and asserts zero writes.

## 5. Failure modes (must be tested)

| Condition | Required behavior |
|---|---|
| Crossing, enforcement disabled | no-op; behavior identical to today |
| `enforce=True`, confirm missing | preview only; zero writes |
| direct mode off / operator off | refusal code `not_direct` / `not_enabled`; zero writes |
| mission not pausable | fail closed: `need_attention`, no dispatch, signal still spooled? NO — signal only after successful pause OR in fail-closed need_attention path with `proposed_action="attention"`; keep one spool entry max |
| policy flips mid-action | abort `policy_changed`; zero writes |
| spool write fails | raise (loud) — INV-10 loudness applies |
| repeat enforcement | `already_enforced`; no duplicate `break` rows |
