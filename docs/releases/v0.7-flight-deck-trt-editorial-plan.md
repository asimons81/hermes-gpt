## 3. Outline (draft structure)

1. **Lede (spine):** Hermes GPT v0.7.0 Flight Deck is finished and
   independently verified, and it still isn't released. That gap is the
   point: the release proves its own "receipts, not reports" thesis.
2. **What Hermes GPT is (1 short paragraph):** local-first MCP sidecar that
   turns ChatGPT/Codex into a control surface for Hermes Agent; Tony's
   existing review is the anchor link. Not a recap of the announcement.
3. **The review surface (`hermes_review_accept`):** production review
   evidence, owner-gated, distinct reviewer enforced in code, bounded
   verdicts, evidence referenced not copied. Contract validation now reads
   the review store. Cite verification.
4. **The event surface (`hermes_events_query`/`tail`):** read-only, redacted,
   no raw bodies, five sources, allowlist, retention window. Effective
   window is min(source retention, configured) — say it exactly that way.
5. **Restart-safe continuity (`hermes_swarm_reconcile`):** blocked with
   `interrupted_by_restart`, never auto-advances, idempotent re-advance,
   dry-run by default. Honest framing: recovery is a tool, not a daemon
   (D5). This is the "what survives a crash" section with real limits.
6. **Durable encrypted tokens:** AES-256-GCM, 0600, restart reload, revoke
   + rotate. Honest fallback framing: key-file path is the weaker one and
   legal sign-off is pending (D6).
7. **MCP currency + seams:** floor 2024-11-05 through 2025-11-25, transports,
   auth metadata; cross-machine is interfaces only, no remote execution.
8. **What's still gated:** live ChatGPT connector verification (G4c), legal
   sign-off on token storage/retention/revoke (G4d), GitHub/PyPI publishing.
   GitHub latest is v0.6.0, PyPI v0.5.0 — no false release claim.
9. **Bottom line:** the bar this sets for agent software: done means
   evidence, and the release walks the same discipline it ships.
