## Escalation triggers

- **R4/R9/R11 (security/data)** — any change to token key management, secret
  paths, or retention windows requires legal sign-off before the slice ships
  (G2/G4).
- **R1** — if Slice 0 cannot restore green CI within the slice budget, block
  and escalate to default; do not weaken or skip failing safety tests.
- **R3** — any proposed weakening of distinct-reviewer enforcement escalates to
  default + legal (product invariant: Work Contract validation fail-closed).
- **R2** — if live ChatGPT connector verification fails at G4, the OAuth
  promotion slice is blocked; do not claim shipped compatibility.

## External counsel checkpoints

1. **Token storage + key management** (ADR-001): before Slice 5 (S5) ships.
2. **Event retention window + review-evidence retention**: before S4/S3 ship.
3. **`hermes_oauth_revoke` surface scope**: before S5 ships.
4. **Positioning claims** (growth lane): any claim must map to implemented
   capabilities; no public claims before G5 (research recommendation #7).
