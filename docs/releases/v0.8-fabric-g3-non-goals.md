# Fabric G3 Security Non-Goals

G3 does not claim:

- cryptographic remote attestation of a fully compromised peer OS;
- safe fine-grained concurrent writers inside one logical workspace;
- safe verified Fabric over remote cleartext HTTP;
- safe coordinator identity from a token shared among unrelated callers;
- safe same-origin rendering of arbitrary active remote artifacts;
- that a peer or worker may certify its own Work Contract completion.

These boundaries are deliberate and must not be softened during G4 implementation.
