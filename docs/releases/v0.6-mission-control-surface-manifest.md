## 1. Audience model

| Who | Access to surfaces | Boundary |
|---|---|---|
| Tony (sole operator, trusted client) | Default: **all** read-only surfaces | Loopback bind; remote only via VPN/private tunnel with auth (cloudflared Access / Tailscale). No public/unauthenticated exposure (NG-MC4). |
| Future third-party client | **None** unless added (G6) | Requires DPA/confidentiality + scoped API; not in v0.6. |

- **AuthN (who):** at the edge — loopback by default; tunnel/VPN is the
  authentication layer (D11). v0.6 ships no OAuth provider.
- **AuthZ (what each client may see):** in the sidecar — operator level
  `read_only` (default) required for every `hermes_mission_*` tool, **plus**
  the per-client `HERMES_GPT_MISSION_ALLOWED_SURFACES` allowlist
  (deny-by-default, D12). Default (env unset) = all read-only surfaces. A
  deployment may restrict to a subset. Denied surfaces return `AUTHZ_DENIED`,
  not a data error.

## 2. Surface manifest (what is exposed, to whom, redacted view)

All surfaces require only operator level `read_only` (never `direct` apply
mode). **Every call is audited** (D10) with `dry_run=true, changed=false`.

| Surface (tool) | Returns (bounded, redacted view-model) | Never returned (HIGH, always excluded) | Sensitivity class |
|---|---|---|---|
| `overview` | One bounded doc: fleet_health, profiles (count/active), fleet_agents (peers/authority), codex, cron, delegations, failures, pending_approvals, vault, usage — each with `available`; `surfaces_unavailable[]` | Raw bodies, prompts, secrets | Composite (LOW/MED only, §8.4 cap 64/128 KB) |
| `health` | Derived `overall` + checks[] (gateway, fleet_authority, vault_store, codex_store, doctor) | Credentials, tokens | LOW |
| `profiles` | per-profile: name, model, provider, gateway_running, cron_jobs/enabled/errors, sessions_7d, last_activity, ticker_heartbeat | auth.json, .env, SOUL.md, memories bodies | LOW/MED |
| `fleet` | peers (name, has_token only), authority (`configured`/`not_configured`), served_profiles | A2A URLs, tokens, task payload bodies | LOW/MED |
| `codex` | operator_store_present, operator_jobs (id,state,timestamps,model,exit), native_sessions count + latest dir, health, fallback_source; `available:false+reason` when absent (G1) | rollout-*.jsonl transcripts, ~/.codex/auth.json, prompts | MED (HIGH excluded) |
| `cron` | jobs (id,name,schedule,enabled,state,next/last run,last_status,last_error capped,deliver target), executions_by_status, scheduler_live | prompt, script body, deliver payload | MED |
| `delegations` | delegations (id,state,origin/parent session,timestamps), kanban_runs (task_id,board slug,assignee,status,outcome,error capped), by_state | task_json, result_json, kanban body/metadata | MED (HIGH excluded) |
| `failures` | recent_errors[] (source,timestamp,message truncated), by_source, vault_denials | raw log lines with secrets | MED |
| `approvals` | approvals[] (kind,source,id,status,`prompt_sha256`,created_at), by_source | raw prompt/blocker bodies | HIGH → sha + label only |
| `vault` | credential_state counts, credential_names (service/alias), leases, pending_requests, access_summary | credential payloads, keys, raw_secret | MED |
| `usage` | sessions_24h, tokens_24h (in/out), estimated_cost_24h_usd, by_profile | message content, prompts | LOW/MED |
| `audit` | records[] (existing audit shape, summary-based, capped), count | anything beyond logged summary | MED |

**Prompt redaction rule (everywhere):** any prompt is represented as
`{prompt_len, prompt_sha256}` only — never the text. Kanban/delegation bodies
are stripped. Codex transcripts and Vault credentials are never returned.
`.env`, `auth.json`, `mcp-tokens/`, `.ssh/`, `.aws/`, `vault/`, and
secret-looking filenames remain denied by the operator policy (D7, §6.3).

## 3. Security boundary

| Control | Status in M0 |
|---|---|
| Network | Loopback bind default; non-loopback surfaces a hard warning (NG-MC4) |
| Edge auth (who) | VPN / Tailscale / private tunnel (cloudflared Access) — the real boundary |
| Sidecar authZ (what) | operator `read_only` + `HERMES_GPT_MISSION_ALLOWED_SURFACES` allowlist (deny-by-default) |
| Redaction | class-based (§6.3) + bounded output (§8.4) — overview 64/128 KB, surface 256/512 KB |
| Audit | `audit_record` on every mission call (D10) |
| Denied paths | `.env`, `auth.json`, `mcp-tokens/`, `.ssh/`, `.aws/`, `vault/`, secret-like |
| No mutation | structural — all SQLite `file:...?mode=ro`; no write/dry-run/apply args; no mutating shell calls |
| Cache | in-process, post-redaction only, TTL-bounded; never caches raw/secret bodies |

## 4. Verification (all fixture-only, never production data)

`test_operator_mission.py` (32 cases) on a temp `hermes_root` fixture covers:

1. Envelope/contract for all 12 surfaces + overview
2. Redaction/no-raw-body (prompts→sha, delegation bodies, kanban body/metadata,
   codex transcripts, vault secrets all absent)
3. Conditional availability (D9): codex/vault absent → `available:false + reason`
4. Read-only guarantee: all SQLite opens are `?mode=ro`; no source file
   created/mutated by any surface
5. Cross-board aggregation (G3) + per-profile aggregation (G7)
6. Overview composition + per-section `available` + truncation (`count_total`)
7. Cache: served_from_cache/age_ms/force_refresh
8. Allowlist (D12): unlisted surface → `AUTHZ_DENIED`; empty → deny all;
   default → all
9. Audit: every mission call appends `dry_run=true, changed=false`

Full suite: `python -m pytest` green (2026-08-13, branch
`feat/m0-mission-control` commit `8e1f31a`). `py_compile` clean on

## 5. Open design decisions inherited (for your awareness)

- **Q1 (authN):** private-tunnel/VPN boundary assumed (D11); no OAuth provider
  in v0.6.
- **Q2/Q5 (approvals):** view-only this release; approval-inbox aggregation
  contract adopted (G4).
- **Q6 (cron deliver):** exposes `deliver` **target name** only (e.g.
  "telegram"), never the payload.
- **Q7 (usage cost):** surfaces `estimated_cost_24h_usd` where `cost_status`
  is known; token counts always.
- **Q8 (size caps):** §8.4 defaults (64/128 KB overview, 256/512 KB surface).
