## 2. Restart reconciliation + idempotent advance (S2) — live

```python
# demo_s2.py (temp root; adapt from the verification exercise)
import json, os, tempfile
from pathlib import Path
os.environ |= {
  "HERMES_GPT_OPERATOR_ENABLED": "1",
  "HERMES_GPT_OPERATOR_LEVEL": "workspace",
  "HERMES_GPT_OPERATOR_APPLY_MODE": "direct",
}
import operator_recovery as rec
import operator_swarm as op_swarm
import test_operator_recovery as tr

root = Path(tempfile.mkdtemp()) / "hermes"
(root / "swarm-workflows").mkdir(parents=True)
tr._write_workflow(root, tr._workflow_record("sw-demo", stage_status="running"))

print(json.loads(rec.hermes_operator_reconcile(apply=False, hermes_root=root))["swarm"])
# -> interrupted_count 1, applied False; stage still running (dry-run)
print(json.loads(rec.hermes_operator_reconcile(apply=True, hermes_root=root))["swarm"])
# -> records_changed 1; stage blocked with reason interrupted_by_restart
wf = op_swarm._load_workflow(root, "sw-demo")
print(wf["stages"][0]["status"], wf["stages"][0]["blocked_reason"])  # blocked interrupted_by_restart
```

Key talking point: fail-closed — reconcile **never** auto-advances; the
operator re-advances through `hermes_swarm_stage_advance`, which is idempotent
for done/validated stages (returns `idempotent: true, changed: false`).

## 4. Structured event history (S4) — live

# demo_s4.py (temp root)
import json, tempfile, os
from pathlib import Path
import operator_events as ev
root = Path(tempfile.mkdtemp()) / "hermes"
for d in ("logs", "swarm-workflows", "codex-jobs",

Key talking point: read-only read-model over 5 sources, no raw bodies,
allowlist semantics (unset=all / list=only / empty=none), retention window
default 90d with effective window `min(source, configured)`.

## 5. Durable encrypted token storage (S5) — live

```python
# demo_s5.py (temp root)
import json, tempfile, stat
from pathlib import Path
import token_store as ts
root = Path(tempfile.mkdtemp()) / "hermes"; (root / "secrets").mkdir(parents=True)
res = ts.save_tokens(hermes_root=root, tokens={
  "issuer": "https://chatgpt.com", "client_id": "hermes-gpt",
  "access_token": "at-demo", "refresh_token": "rt-demo", "expires_at": "2026-08-16T00:00:00+00:00"})
print(res)  # kid/source (keyfile on this host), path
env = root / "secrets" / "hermes_gpt_tokens.json"
print(oct(stat.S_IMODE(env.stat().st_mode)), "at-demo" in env.read_text())  # 0o600 False
print(ts.load_tokens(hermes_root=root)["access_token"])  # restart roundtrip
print(ts.revoke_tokens(hermes_root=root, rotate_key=True))  # revoked, key rotated
```

Key talking point: AES-256-GCM, 0600, no plaintext on disk, restart reload,
corrupt envelope fails closed, owner-gated revoke. On this host key source is
`keyfile` (no keyring) — the documented weaker fallback; legal sign-off
pending (gate, not code).
