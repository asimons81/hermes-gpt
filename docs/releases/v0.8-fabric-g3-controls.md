# Fabric G3 Control Index

Normative controls for Hermes GPT v0.8 Fabric after adversarial security review:

- G3-S01: unique authenticated coordinator principal
- G3-S02: authenticated encrypted cross-machine transport
- G3-S03: server-defined write conflict domain
- G3-S04: full execution-unit/process-tree terminal proof
- G3-S05: immutable finalized artifact snapshot
- G3-S06: immediate pre-start policy revalidation
- G3-S07: closed security-critical schemas
- G3-S08: check-specific evidence provenance
- G3-S09: untrusted active-artifact isolation
- G3-S10: injection-safe structured audit lineage

The detailed requirements, attack reasoning, regression obligations, and fail-closed results are defined in `v0.8-fabric-security-review.md` and `v0.8-fabric-risk-register.md`.
