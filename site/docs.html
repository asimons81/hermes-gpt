Documentation • v0.16.0

Close the loop. Keep approval in human hands.

Install Hermes GPT, connect a trusted client, route Owner inbox items to the places you check, and act on them through gated tools. These links open the canonical repository guides, which stay the source of truth for current behavior.

Start with the quickstartv0.16.0 release

Get connected

Install and update

Python 3.10+. Install hermes-gpt 0.16.0 from PyPI; verify GitHub and PyPI independently when updating.

Connector tool profiles

Choose full, operator, or chat-lean with HERMES_GPT_TOOL_PROFILE. A profile only removes tools and never bypasses a gate.

Private OpenAI access

Use the outbound-only private tunnel path to reach loopback Hermes GPT from supported OpenAI products.

Codex as a client

Configure Codex to use Hermes GPT. Client setup and delegated Codex CLI execution have separate authority gates.

Notify and act

Owner notifications (default off)

Set HERMES_GPT_ATTENTION_DELIVERY=1 and HERMES_GPT_ATTENTION_TARGETS to relay new inbox items through hermes send or imsg rpc. Messages are notifications only; replies do nothing.

Flight Deck inbox actions

Each action is a dry run followed by a confirm, and calls the existing gated tool. Acknowledging an item with hermes_owner_inbox_ack does not resolve the condition.

One-call Mission launch

hermes_mission_launch requires HERMES_GPT_AUTOPILOT=1, is dry run by default, stops at the first refusal, and never approves a Mission. Re-running it creates a new Mission.

Safe package upgrade

hermes-gpt update --apply --version 0.16.0 upgrades one virtual environment after a digest check, with a rollback snapshot. Installing a release does not turn on any gate.

Review the Owner loop

Owner inbox (read-only listing)

hermes_owner_inbox lists Missions awaiting approval, Autopilot runs waiting for the Owner, controller attention, and Work Contracts awaiting review. It writes nothing; check sources and complete first.

Advisory review assist

Default off. Needs HERMES_GPT_ENABLE_JEV=1 and HERMES_GPT_REVIEW_ASSIST=1. A score is advisory only and is never review acceptance or Work Contract evidence.

Jev decisions (default off)

Three typed judgments reuse a pinned adapter and are registered only with HERMES_GPT_ENABLE_JEV=1. Installing the package does not provision the Owner key or activate the gate.

Declare, observe, recover

Autopilot and acceptance

Declare artifact minimum/maximum sizes and optional expected SHA-256 values before dispatch. Requirements survive bounded rework unchanged.

Delivery grace and recovery

Confirmed artifact failures after successful execution get a durable 30-second grace. Recovery proceeds within existing bounds only when every other required check passes.

Flight Deck supervision

Read-only completion checks, fixed failure reasons, delivery grace, and pending validation. Changing or unreadable evidence remains unverified.

Understand the boundaries

Operator and Owner policy

Default read-only behavior, dry-run-first mutations, explicit authority, and secret-path protections. Autopilot remains default off.

Missions and approval

Autopilot stops at approval frontiers. Final Mission approval remains Owner-only; size and integrity checks do not judge semantic quality.

Authentication and compatibility

Configure bearer or OAuth authentication for trusted clients. Public unauthenticated Operator hosting is unsupported.

v0.16.0 release notes

Notifications, Owner inbox actions, one-call Mission launch, and safe upgrades. Calls to Jev send supplied text to TypeSafe and may incur charges.

Verify the running installation

Check service provenance, shared environments, authenticated tool discovery, acceptance, and rollback before claiming an update is live.
