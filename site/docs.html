Get connected

Install and update

Python 3.10+. Install hermes-gpt 0.15.0 from PyPI; verify GitHub and PyPI independently when updating.

Connector tool profiles

Choose full, operator, or chat-lean with HERMES_GPT_TOOL_PROFILE. A profile only removes tools and never bypasses a gate.

Private OpenAI access

Use the outbound-only private tunnel path to reach loopback Hermes GPT from supported OpenAI products.

Codex as a client

Configure Codex to use Hermes GPT. Client setup and delegated Codex CLI execution have separate authority gates.

Review the Owner loop

Owner inbox (read-only)

hermes_owner_inbox lists Missions awaiting approval, Autopilot runs waiting for the Owner, and controller attention. It writes nothing; check sources and complete first.

Advisory review assist

Default off. Needs HERMES_GPT_ENABLE_JEV=1 and HERMES_GPT_REVIEW_ASSIST=1. A score is advisory only and is never review acceptance or Work Contract evidence.

Jev decisions (default off)

Three typed judgments reuse a pinned adapter and are registered only with HERMES_GPT_ENABLE_JEV=1. Installing the package does not provision the Owner key or activate the gate.

Declare, observe, recover

Autopilot and acceptance

Declare artifact minimum/maximum sizes and optional expected SHA-256 values before dispatch. Requirements survive bounded rework unchanged.

Delivery grace and recovery

Confirmed artifact failures after successful execution get a durable 30-second grace. Recovery proceeds within existing bounds only when every other required check passes.

Flight Deck supervision

Read-only completion checks, fixed failure reasons, delivery grace, and pending validation. Changing or unreadable evidence remains unverified.

Understand the boundaries

Operator and Owner policy

Default read-only behavior, dry-run-first mutations, explicit authority, and secret-path protections. Autopilot remains default off.

Missions and approval

Autopilot stops at approval frontiers. Final Mission approval remains Owner-only; size and integrity checks do not judge semantic quality.

Authentication and compatibility

Configure bearer or OAuth authentication for trusted clients. Public unauthenticated Operator hosting is unsupported.
