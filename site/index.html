Fabric

Remote execution without surrendering authority.

Remote worker self-report is transport data, not proof of completion. Fabric keeps placement, evidence admission, reconciliation, contract validation, and approval anchored to the coordinator.

01

Authenticated Fabric Peers

The packaged hermes-gpt-fabric-peer runtime handles remote execution. Non-loopback peer serving requires direct TLS with both certificate and key.

02

Capability-Aware Routing

Durable capability manifests, health and freshness state, deterministic ranking, exclusion reasons, backend availability, profile policy, workspace constraints, and authority ceilings all feed placement.

03

Verified Artifacts

Remote artifact admission uses immutable manifests and content hashing. The coordinator verifies received bytes instead of trusting a worker claim.

04

Same-Attempt Reconciliation

Restart, timeout, and cancellation recovery reconcile the original distributed attempt when possible. Write-ownership and write-epoch guards block duplicate or ambiguous mutation paths.

05

Fabric Flight Deck

Read-only node, placement, attempt, evidence, and routing views expose the authoritative selected route, including health, capability freshness, eligibility, transport backend, and authority ceiling.

06

Real Two-Machine Acceptance

The final Fabric target passed fresh G6 acceptance on distinct Linux machines with authenticated remote execution, induced transport loss, same-attempt recovery, artifact re-hash, fail-closed missing evidence, Work Contract validation, approval gating, and independent review.

System Architecture

Coordinator authority, distributed execution.

Hermes GPT remains a local-first sidecar. Fabric adds authenticated remote placement while keeping the trusted coordinator authoritative.

01Client Request

ChatGPT, Codex, Cursor, Claude Desktop, or another trusted MCP client submits a bounded request to Hermes GPT.

02Policy + Placement

The coordinator evaluates Operator level, workspace, backend, node health, capability freshness, and authority ceiling before selecting an eligible route.

03Local or Remote Execution

The bounded stage runs locally or through an authenticated Fabric peer. Explicit operator overrides remain preserved.

04Evidence + Validation

Evidence and artifacts return to the coordinator, which performs admission, hashing, Work Contract validation, reconciliation when needed, and final approval gating.

Capabilities

Local-first control plane, now distributed.

v0.8 adds Fabric without weakening the security and evidence invariants shipped in earlier releases.

01

Operator and Owner Policy

Tiered authority from read_only through owner, with explicit direct mode, confirmation gates, and dry-run-first mutation.

02

Work Contracts

Completion is validated from observed state. Missing required evidence cannot become SATISFIED.

03

Swarm Orchestration

Bounded DAG workflows with explicit ownership, capped concurrency, review independence, rework limits, and final human approval.

04

OpenAI Secure MCP Tunnel

Supported OpenAI products can reach loopback Hermes GPT through an outbound-only private tunnel path without publishing a public Hermes GPT hostname.

05

Bounded Binary Export

hermes_export_file provides workspace-authorized binary transfer with denied-path enforcement, symlink escape refusal, size caps, extension controls, and safe audit metadata.

06

Flight Deck + Diagnostics

Mission Control, event history, review evidence, diagnostics, recovery tools, and Fabric routing views keep long-running autonomy inspectable without creating a bypass.

Install

Get Hermes GPT running.

Install from PyPI or run the current checkout. Keep the HTTP server on loopback unless you deliberately configure an authenticated private boundary.

Install package
python -m pip install hermes-gpt

Check the PyPI badge in the repository README before relying on version-specific features.

Run current source
git clone https://github.com/asimons81/hermes-gpt.git
cd hermes-gpt
python -m pip install .
hermes-gpt
Loopback Streamable HTTP
python server.py --http --host 127.0.0.1 --port 7677

Endpoint: http://127.0.0.1:7677/mcp. For supported OpenAI products, prefer the OpenAI Secure MCP Tunnel path documented in the repository.
